# DevSecOps Pipeline Project

## 1. Nama Aplikasi & Fungsi

- **Nama Aplikasi**: Secure User API Service
- **Fungsi**: Layanan backend REST API sederhana untuk pengujian integritas pipeline CI/CD dan pemindaian keamanan kode (SAST).

## 2. Bahasa & Framework

- **Bahasa**: Python 3.10
- **Framework**: Flask
- **Testing Tool**: Pytest
- **SAST Tool**: Bandit
